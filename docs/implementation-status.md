# 实现状态与交付边界

更新日期：2026-10-22。文档版本：v1.5。当前状态：**三端自动构建已配置 / 真实目标环境待验收**。

## 当前产品行为

Windows 公告助手绑定后完全在系统托盘后台待机，不显示常驻公告墙、公告卡或时钟。只有收到新消息或定时消息到点生效时，才按消息自身的展示位置出现约 15 秒的非激活提醒：居中窗口约 760×480、正文大字；右上角浮窗约 460×300。Electron 源码使用不可聚焦窗口、`showInactive()` 和默认鼠标穿透，设备语音默认关闭；刷新、启动和断线重连都不补弹历史。浏览器预览只证明网页行为，不能证明 Windows 原生窗口尺寸、焦点、穿透和托盘行为。

小程序使用微信原生 JavaScript/WXML/WXSS，底部为“班级 / 记录 / 我的”。发布类型为“呼叫学生”“作业布置”“普通通知”。首页选择教室后，发布页固定当前教室；普通通知的其他教室列表排除当前教室。每条消息单独选择右上角浮窗或居中窗口，展示排序页只管理置顶和顺序。呼叫和作业共用已选学生状态，没有独立的“批量呼叫”入口；1 名学生显示个人呼叫，2–3 名学生显示多人呼叫。

记录卡提供详情、编辑和删除。编辑时目标教室锁定；删除即撤回，消息从有效列表移除，置顶被清理，状态和 revision 更新并写入审计，历史消息与投递回执仍保留。

服务端已验证 `GET/PUT /rooms/:id/display-settings` 的同教室共享与顺序规则；设置修改会增加 `revision` 并产生 `room.display`。消息级展示位置、编辑目标教室锁定、删除即撤回、置顶清理和审计记录也有自动化覆盖。呼叫与作业缺少 `destination` 会被 API 拒绝。普通通知使用教师填写的标题；呼叫与作业的标题分别为 `呼叫 · 到 <destination>` 和 `批量作业 · <count>人 · <destination>`。

班级删除对不存在对象返回 404，对仍有学生的班级返回 409 `CLASS_IN_USE`。换教室要求 `confirmImpact: true`，且不会自动迁移既有公告。小程序修改班级使用 `POST /admin/classes/:id/update`；PATCH 仅作为其他客户端的兼容入口。

## 三端自动构建与交付配置

仓库已写入以下自动构建和部署路径：

| 路径 | 已配置内容 |
| --- | --- |
| `Project checks`（CI） | `.github/workflows/ci.yml` 执行 `./scripts/check.sh` 与 `node scripts/smoke.mjs` |
| `Server image` | `.github/workflows/docker.yml` 使用 Docker Compose 构建 API、启动容器检查 `/healthz`、推送 `ghcr.io/alumos/tipsforclass-api`，并导出 Linux amd64 离线镜像包及其 SHA-256 |
| 国内 VPS | `compose.yaml` + `deploy/Caddyfile` 提供持久 SQLite 卷、API 健康检查、可选 Caddy HTTPS/WSS 反代；可拉取 GHCR 镜像，也可 `docker load` 离线镜像包 |
| `Windows installer` | `.github/workflows/windows.yml` 在 `windows-2022` 生成 x64 NSIS 安装包与 `SHA256SUMS.txt`；推送 `v*` 标签生成 GitHub Release 的触发条件已配置 |

以上是仓库中的配置事实。本记录没有收录 GitHub 远程运行日志、GHCR 推送结果、产物下载、Release 创建或 Windows 实机安装结果，因此不把这些工作流写成已运行通过、已发布或已验收。

## 当前已知差异

- 服务端仍接受教室级 `displayPosition` 以兼容旧消息和旧客户端，但当前发布/编辑流程使用消息自身字段，展示排序页只管理置顶和顺序。
- 记录页“删除”是保留历史的撤回操作，不会物理删除消息或投递回执；隐私清理是另一条受策略控制的数据保留流程。
- 浏览器预览与 Electron 共享同一套 Vue 页面和同步逻辑，但浏览器窗口不能验证 Windows 原生 `showInactive`、不可聚焦、鼠标穿透或托盘行为。

## 与设计文档的实施取舍

- 小程序采用无 npm 构建的原生 JavaScript/WXML/WXSS 和自定义样式，没有引入额外组件库。
- 首版单校服务的实际 SQL 以 `server/internal/app/schema.sql` 为准；HTML 中的 DDL 是设计基线，不是可直接覆盖运行中数据库的迁移文件。
- 微信请求方法限制下，教师、教室和班级修改提供 POST `/:id/update`；PATCH 只保留给其他兼容客户端。
- v1.5 将交付状态同步为“三端自动构建已配置、真实目标环境待验收”，并记录 Docker/Compose/Caddy、GHCR/离线镜像、Windows NSIS/SHA-256 与 `v*` Release 触发条件；这些配置不被写成远程运行或目标环境已通过。
- v1.4 将 Windows 默认行为修订为绑定后完全托盘待机，只在收到新消息或定时消息生效时显示两类短时提醒；HTML 设计文档、实施状态与验证记录同步记录该行为。
