# 体验版自用指南：3 人以内，不备案

本文适用于**只在校内 3 位教师之间使用、永不提交审核发布**的场景。此路径不需要小程序备案，也不需要等待通信管理局审核。

一旦要加第 16 位成员、要给家长或学生打开、或希望对方自己搜到，必须转 [正式发布流程](miniapp-release.md)，那时备案无法绕开。

## 0. 先理解边界

微信约束的是「有没有正式上架」，不是「有多少人用」。只上传体验版、不点"提交审核"，就不触发备案要求；平台清退也只清退线上正式版本，体验版不受影响。

代价是体验版的四个硬限制（个人主体）：

| 限制 | 说明 |
| --- | --- |
| 成员上限 15 人 | 后台手动添加微信号，超出无法使用；企业主体名额更多，以成员管理页显示为准 |
| 不能被搜索、不能转发 | 非成员扫码打不开，只能由你添加后再进 |
| 不能添加到手机桌面 | 只能从微信收藏或扫二维码进入 |
| 更新要重新上传 | 改代码后重新上传并重新"选为体验版"，成员退出重进即可生效 |

3 人规模下这些限制可以接受，多于 8 人就开始难受了。

## 1. 体验版同样需要满足的技术前提

不备案 ≠ 可以不管域名。微信校验的是「服务器域名是否合法」，这条和备案无关，但同样卡人：

1. API 域名已完成 ICP 备案（本项目使用 `alomos.cn` 及其子域名）。
2. 域名有有效 HTTPS 证书，证书链完整，**不能带端口**（`https://notice.example.cn` 可以，`https://notice.example.cn:8443` 不行）。
3. 服务端以生产模式运行：

```dotenv
APP_MODE=production
WECHAT_APP_ID=你的AppID
WECHAT_APP_SECRET=你的AppSecret
```

`curl https://你的域名/healthz` 应返回 `"mode":"production"`。

如果给公告系统单独开子域名（如 `notice.alomos.cn`），需要在腾讯云做一次「新增域名」备案，同主体下通常 1–3 个工作日，不重做主体核验。想完全省掉这一步，也可以复用 `gomoku.alomos.cn` 并在 Caddy 里加一段 `/notice/*` 反向代理，代价是两个服务共享域名和证书配置。

## 2. 配置微信合法域名

微信公众平台 → **开发管理 → 开发设置 → 服务器域名**：

- request 合法域名：`https://你的域名`
- socket 合法域名：`wss://你的域名`

这一步在开发阶段就能配置，不需要先备案、也不需要先发布。配置后通常几分钟生效。

## 3. 改小程序生产配置

`miniapp/config.js`：

```js
module.exports = {
  apiBase: 'https://你的域名/api/v1',
  enableDemoLogin: false
};
```

`enableDemoLogin: false` 必须改。生产服务本身不提供演示登录，留着 true 会在体验版上直接报错。

`miniapp/project.config.json` 里的 `urlCheck: false` 只对开发者工具本地生效，**真机体验版仍按后台白名单校验**，所以第 2 步不能省。

## 4. 上传并设为体验版

1. 微信开发者工具导入 `miniapp/` 目录，确认 AppID 为 `wxa4083506823513ec`。
2. 本地先跑检查：

```sh
cd miniapp
npm test
npm run check
```

3. 工具右上角「上传」，版本号填 `0.1.0`，备注写"校内试点：公告发布、名册、设备绑定"。
4. 微信公众平台 → **管理 → 版本管理** → 开发版本 → 右侧「选为体验版」。
5. 生成体验版二维码，先用自己的手机扫一遍。

## 5. 添加成员并分发

微信公众平台 → **管理 → 成员管理 → 体验成员 → 添加**，输入对方的微信号（不是手机号，也不是昵称），最多 3 人。

分发方式按实用性排序：

1. 把体验版二维码图片存进微信「收藏」，本人和同事都存一份，日常从收藏打开。
2. 打印一张贴在办公桌或教室讲台，扫码即进。
3. 不要发到家长群、教师大群或公开场合——非成员打不开，还会引来"这是不是正规小程序"的质疑。

## 6. 日常更新流程

改了小程序代码后：

1. 重新「上传」，版本号递增（`0.1.1`）。
2. 后台「版本管理」里对新上传的开发版本再点一次「选为体验版」。
3. 同事退出小程序重新进入，即为新版本。二维码不变，不用重新加成员。

改了服务端代码则不需要动小程序，直接重建容器即可。

## 7. 常见问题

| 现象 | 排查方向 |
| --- | --- |
| 真机白屏或请求失败 | `config.js` 还是 `127.0.0.1`；或服务器域名没配 |
| 提示"域名不合法" | 域名未备案、证书链不完整、用了端口或 IP |
| 微信登录失败 | 服务端 `WECHAT_APP_ID`/`SECRET` 与 AppID 不配套；`APP_MODE` 不是 production |
| 同事扫码提示无权限 | 没加体验成员，或加错微信号 |
| 「上传」按钮灰色 | 当前微信号不是该小程序的开发者，先在成员管理里加项目成员 |
| 体验版连不上 WSS | socket 合法域名没配，只有 request 域名不够 |

## 8. 什么时候必须转正式备案

出现任意一条，就该走 [正式发布流程](miniapp-release.md)：

- 使用人数超过 15 人（或预计一学期内会超过）；
- 希望家长、学生自己打开查看记录；
- 希望对方扫一扫就能用，不想每次手动加成员；
- 希望添加到手机桌面、减少日常操作步骤；
- 学校要求以单位名义对外提供。

正式备案本身免费，材料是身份证、手机号、人脸核身，流程约 30 分钟填写 + 1–20 个工作日等待。难点在主体与类目匹配，见发布教程第 1、6 节。
