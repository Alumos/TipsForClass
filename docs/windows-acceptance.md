# Windows 10/11 课堂设备验收

此清单用于学校实际电脑；Mac上的构建成功或浏览器效果不能自动填“通过”。

## 先记录

Windows版本/构建号、PPT/WPS版本、显示器数量和分辨率、缩放比例、音频输出设备、还原软件、运行账户。使用虚构学生资料验收。

## 背景驻留和不打断课件

1. 首次打开完成绑定。已绑定后重新启动，确认只在系统托盘运行，任务栏不出现自动激活的公告主窗口。
2. 打开PPT放映，持续用键盘翻页；另一个人从小程序发普通通知。
3. 浮层显示时，继续翻页、打字和点击；确认当前活动窗口仍为课件。
4. 在浮层覆盖区域点击原课件可交互内容，确认点击穿透，不被浮层吞掉。
5. 约15秒后浮层自动隐藏；小程序显示设备实际收到/展示，默认没有声音。
6. 连续发送多条消息，确认提醒不会持续霸占屏幕，剩余公告可从托盘查看。
7. 托盘暂停提醒后再发公告：后台可以接收，不能自动显示或播音；恢复后不连弹暂停期间旧消息。
8. 重启程序、断网重连：不突然补弹历史公告；未来定时公告按约定生效。
9. 关闭查看/设置窗口回托盘；选择退出可正常终止，不能阻挡老师使用电脑或关机。
10. 分别用PPT、WPS、浏览器课件和视频播放器重复测试。独占全屏或锁屏时未显示不应通过强制激活其他窗口解决。

## 内容和声音

- 公告长标题、名单和正文不越界；完整信息能在主动打开的公告页查看。
- 校验鼠标穿透不影响全文查看：查看全文必须从托盘主动进入交互窗口。
- 只有明确打开设备语音开关后才测试中文播报，系统其他应用音量不被改变。
- 无中文voice或适配器失败时显示可理解的状态，不能上报已播放。
- 正在播报时撤回立即停止；重复推送不重复念，人工重播生成新任务。
- 静默时段按学校时区处理；暂停提醒/静音与公告计划播报次数分别显示。

## 网络、安装和恢复

- 断网仍可从托盘查看允许保留的有效公告；过期内容不复活。
- 设备吊销后失去访问权限，清除本地授权并提示管理员重新绑定。
- 显示器拔插、100%/125%/150%缩放、1366×768和1920×1080下，浮层没有跑到屏幕外。
- 标准用户可运行，凭据不能以明文存在配置文件。
- 安装包、卸载、程序异常退出和重新启动分别验证；自动更新功能未实现时不要勾选“已通过”。

把失败现象、复现步骤和实际结果记录下来，再决定是否进入一个班级的试用。
