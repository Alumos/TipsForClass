# 班级公告 · 微信小程序

这是可以直接导入微信开发者工具的原生小程序，使用 JS、WXML、WXSS。**不需要安装 npm 依赖、不需要“构建 npm”**。界面使用服务端真实数据；初始示例名册也从 Go API 获取，没有假回执。

正式上线流程见 [微信小程序发布教程](../docs/miniapp-release.md)，国内 VPS 与 HTTPS 域名配置见 [Docker Compose 部署](../docs/deployment.md)。仅在 3 人以内自用、不打算上架时，走 [体验版自用指南](../docs/miniapp-trial.md)，无需小程序备案。

## 第一次运行：照着做

1. 先按仓库根目录 README 启动 Go 服务，使用明确的 `APP_MODE=demo`。默认服务为 `http://127.0.0.1:8080`。在电脑浏览器打开 `/healthz` 确认服务已启动。
2. 安装并打开微信开发者工具，使用微信扫码登录。
3. 选择“导入项目”。项目目录选择**当前 `miniapp` 文件夹**，不要选仓库根目录。项目名称可填“班级公告”。
4. 本地演示可先使用测试号；正式联调前，把 `project.config.json` 的 `appid` 替换成你在微信公众平台注册的小程序 AppID。
5. 保持“开发模式”为“小程序”，确认导入。项目没有 npm 构建步骤，工具会直接编译。
6. 确认 `config.js` 中 `apiBase` 为 `http://127.0.0.1:8080/api/v1`，`enableDemoLogin` 为 `true`。
7. 开发者工具右上角“详情 → 本地设置”，仅本地联调时勾选“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”。项目配置默认关闭域名校验；若工具仍报错，检查此项。
8. 在模拟器登录页点击**“进入本地演示”**。不要点击“微信身份登录”冒充真实登录；后者需要真实 AppID 和服务端微信配置。
9. 打开底部 **“我的 → 管理班级与教师 → 班级与绑定”**，选择班级，点击“生成大屏绑定码”。
10. 按根 README 启动 Windows 公告助手或电脑浏览器预览，在其绑定页面输入六位码。绑定码 10 分钟有效、一次性使用；响应丢失请重新发码。没有设备的班级禁止发布。
11. 回到“班级”，下拉刷新后点击已绑定班级，选择示例学生，按需填写地点；作业布置还需填写作业内容，然后点击发布。
12. “投递详情”展示真实的设备接收、显示提醒、实际播报回执。电脑只在收到新消息或定时消息到点时短暂弹出提醒，随后回到托盘待机；设备语音默认关闭。需要播报时，由设备管理员在电脑端明确开启。

创建正式名册：在管理页先创建班级，再打开“学生名册”。可以从微信聊天中选择 `.xlsx` 文件，上传到 `POST /admin/rosters/xlsx`，以 `classId` 指定班级；服务端返回预检结果后，再点击“确认导入”。文件前两列应为学号、姓名，可以带表头，单批最多 1000 人，学号按文本保留前导零。也可以直接粘贴两列文本：

```csv
学号,姓名
2026001,陈小禾
2026002,林一诺
```

粘贴模式可直接使用 Excel / WPS 的两列单元格（制表符文本）或 CSV。学号保留前导零，支持引号、逗号、CRLF，每次最多 1000 行；同学号更新姓名，未列出的学生不会自动删除。上传和粘贴模式都会先预检，确认前不会写入名册。

同一班级的学生名册由所有已授权教师共同使用。管理员新增、编辑或删除班级，以及导入名册，会影响所有能看到该班级的教师；编辑或删除确认框会明确提示共享影响。

## 真机与真实微信登录

- 手机上的 `127.0.0.1` 指手机自身，不能访问电脑。开发调试时把 `config.js` 地址改为电脑可访问的局域网 IP，手机和电脑连接同一网络，并确认服务监听地址及防火墙允许访问。真机 HTTP/域名限制以开发者工具当前调试能力为准；生产一定使用合法 HTTPS 域名。
- 在微信公众平台获取学校小程序的**真实 AppID**，替换 `project.config.json` 的 `appid`；服务端配置相同 AppID 与 AppSecret。AppSecret 不得写入小程序。
- 配置 HTTPS API，在微信控制台配置 request 合法服务器域名，将 `config.js` 的 `apiBase` 改为 `https://学校域名/api/v1`，设置 `enableDemoLogin: false`，并使用生产模式服务。重新启用工具域名检查后验证。
- 首位管理员微信登录后，在“我的”输入运维提供的一次性初始化码与姓名。之后新教师先微信登录，得到待审核身份；管理员在“教师权限”按申请编号核验，设置姓名、审批通过、分配班级。
- API 身份状态为 `pending / active / disabled`；界面分别显示待审核、已通过、停用。为避免保存中途失去管理权限，自己账号的降级/停用交由另一位管理员操作。
- 教师与班级修改使用 `POST /admin/teachers/:id/update`、`POST /admin/classes/:id/update` 兼容路由；微信原生 `wx.request` 不支持 PATCH。服务端仍可为其他客户端保留 PATCH。

## 页面与行为

- 三个底部入口：班级、记录、我的。管理入口只向已通过的管理员显示。
- 呼叫学生 1–3 人、作业布置 1–60 人，两种模式共用同一份学生勾选结果；选中 1 人显示个人提醒，选中多人自动显示多人提醒。呼叫与作业的地点均必填，作业内容也必填。所有模式默认不播报（语音轮数为 0）；呼叫默认 40 分钟有效，作业默认 2 小时有效。普通通知可发 1–20 个班级，默认今日 22:00 到期（已过则次日）。所有时间按学校 UTC+8 显示。
- 抽屉支持班级、姓名/学号筛选，显示学号尾号；“选择当前筛选”仅选择明确展示的筛选范围，超过限制会阻止选择。切换班级清空学生并提示。
- 网络失败保留表单和完整提交体，包括 `startAt`、`clientToken`。原样重试复用 UUID；修改内容后生成新 UUID。UUID 只用于幂等去重，不是安全凭据。
- 草稿按账号和班级隔离，最长 24 小时，重新进入先读取当前权限与名册，再剔除失效目标。退出登录清除当前账号草稿。403 清除草稿并阻止重新保存。草稿保存在微信本地存储中，请使用学校控制的设备。
- 投递详情每 2 秒查询，最长 30 秒，隐藏页面即取消请求；之后可手动刷新。收到、实际显示和播报是不同状态，不将 HTTP 成功伪装成已显示。
- 管理支持教师审批与班级授权、创建班级、班级新增/编辑/删除、绑定码、XLSX/CSV 名册预检与导入、设备吊销、学校静默时段。静默不会隐藏提醒，语音仍受设备开关控制。
- “屏幕排序”可从班级页、记录页或各班级入口打开。页面按班级读取和保存 `GET/PUT /classes/:id/display-settings`，支持右上角/居中位置、置顶/取消置顶、上移/下移；保存后等待大屏同步应用。

## 常见问题

| 现象 | 检查方法 |
| --- | --- |
| 网络未确认 | Go 服务是否运行；`apiBase` 是否正确；工具域名校验是否关闭；真机是否误用了 127.0.0.1 |
| 演示入口报不存在 | 服务端是否明确使用 demo 模式；生产服务有意不提供演示登录 |
| 微信登录失败 | 是否填真实 AppID、服务端是否配置同一 AppID/AppSecret；测试号不能代替真实微信身份 |
| 没有可发布班级 | 管理员先审批为 active，再给教师分配班级，随后刷新权限 |
| 尚未绑定设备 | 管理生成码后，在电脑公告助手完成绑定，再刷新班级页 |
| 已接收但未显示 | 可能是预约未生效、设备暂停提醒、提醒排队或网络未同步；查看实际回执，手动刷新 |
| 没有声音 | 默认设备静音；需电脑端管理员开启，且消息设置播报、学校非静默、任务未过期 |
| 错误附排查编号 | 将该 requestId 和发生时间告知运维，避免发送学生名单或凭据 |

## 开发检查

如果电脑已安装 Node.js，可在 `miniapp` 目录运行（不需要 `npm install`）：

```sh
npm test
npm run check
```

测试覆盖 CSV 与 XLSX 学号前导零、Unicode 字数、默认时间与跨日、类型限制、UUID、提交超时原样重试、草稿身份隔离和过期清理、详情页面隐藏后恢复与过时请求丢弃、屏幕排序的 GET/PUT 载荷，以及 XLSX 上传到 `/admin/rosters/xlsx` 的班级参数。`check` 检查全部 JSON、JS 语法、页面路由、WXML 标签结构、不支持的方法调用，以及六个 81×81 RGBA 透明 Tab 图标的路径、尺寸、颜色和透明通道。它们不能替代微信开发者工具编译或真机验收。

## 当前验证边界

原生页面代码与接口已实现，但此开发环境没有微信开发者工具自动化会话，尚未实机编译、扫码或 iOS/Android 验证。上线前需在工具编译并真机检查登录、320–430px 布局、键盘、安全区、断网重试以及微信隐私/主体/域名设置。没有承诺已通过微信审核。原始设计文档中的 TDesign/TypeScript 方案在本次试点改用零依赖原生 JS，以便首次使用者直接导入；样式集中在 `app.wxss`。
